# MZ Inbox artwork

The application icon and menu bar rabbit are original geometric artwork generated by
[`scripts/create_inbox_icon.swift`](../../../scripts/create_inbox_icon.swift) and
covered by the repository MIT license. The generator draws its own paths and does
not extract Apple symbols, emoji, Shortcuts assets, or other third-party images.

`AppIcon.png` and `AppIcon.icns` contain the white rabbit on a coral background.
`RabbitTemplate.png` is the monochrome menu bar template. Pausing adds a separate
pause indicator. The filenames are retained for compatibility with the app bundle.

Regenerate on macOS:

```sh
swift scripts/create_inbox_icon.swift
```

The phone shortcut separately chooses a built-in Shortcuts glyph by identifier;
its system-rendered appearance is not redistributed as project artwork.
