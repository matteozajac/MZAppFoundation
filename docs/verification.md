Local environment: Xcode 27 beta (`27A5252f`), Apple Swift 6.4. Package language mode is Swift 6 and minimum tools version is 6.2. CI is configured independently for Xcode 26.6 on the macOS 26 runner.

- 16 Swift Testing core tests, including eight malformed-deep-link cases: typed analytics, schema filtering, independent/local delivery, engine failure isolation, developer defaults/persistence, purchase outcomes, restore, revocation, stream completion, mock isolation, stale-response ordering and redaction. Core has no external dependencies.
- Five Python/Ruby setup fixture tests: new and partial XcodeGen projects, native Xcode projects, exact repeat-run project stability, unsafe manifest/path rejection, and unresolved vendor-import detection.
- XCTest UI flow on iOS 26.5: record an event, complete a simulated purchase, open Pulse, close it and return to the app.
- iOS and visionOS local sample builds and simulator launches. Both local binaries contain Pulse and have no RevenueCat, Sentry, Firebase Analytics or GoogleAppMeasurement symbol/bundle matches.
- iOS and visionOS Internal and Release device compositions compile without signing. Both optimized Release binaries retain Pulse symbols.
- A fresh app generated by `setup.py apply` compiles. Its local binary passes the same SDK-exclusion audit.
- visionOS console auto-opening has runtime evidence: one `developer_console_opened` event written by the console view's `onAppear` into the sample's own Pulse store after launch, without pressing its console button. The sample also has an explicit multiple-scene manifest.
- Setup skill frontmatter validation and staged-source Gitleaks scan.
- Symbol uploader safely skips non-archive/local execution.

Full tool results, logs and binary-audit receipts are retained locally under `output/` and XcodeBuildMCP's workspace logs, outside Git. UI test results are retained in the XcodeBuildMCP result bundle.

## Compatibility findings

Pulse 5.2.3 failed to compile on visionOS due to an unguarded `glassEffect` call in its search toolbar. Pulse 5.2.1 is the verified cross-platform pin. Sentry's replay options exist on iOS but not visionOS, so the explicit replay-disable configuration is iOS-only. Firebase's AnalyticsCore package product is imported as the `FirebaseAnalytics` Swift module.

The simulator tap helper sometimes reported successful taps without activating controls after scrolling. XCTest exercised the actual app flow successfully; helper return status alone was not used as interaction proof.

## Not claimed

No physical-device shake test, real purchase/restore, Firebase event ingestion, Sentry crash ingestion, signed archive, live symbol upload/readback, provider provisioning, TestFlight distribution or store release was performed. Samples deliberately contain no provider credentials or real product catalog. The skill's provider workflow is implemented as agent instructions using connected tools/CLI/computer use; `setup.py` performs local wiring only.

Existing TwinGlyph, Masseter, Second Take, Roamline and JoinOurDay repositories remain unchanged. Their migrations are documented but not executed.
