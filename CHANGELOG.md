# Changelog

This project uses versioned tags. Before 1.0, review release notes and pin a
validated version; APIs and integration requirements may change.

## Unreleased

- Prepare original project code and artwork for MIT-licensed distribution.
- Add public setup guidance, contributor and security policies, issue templates,
  dependency notices, and automated secret scanning.
- Use HTTPS package URLs for new and updated host integrations.
- Include the existing MZ Inbox companion and report-routing tooling as source;
  it is not a signed or notarized public binary distribution.

## Published history

- [0.6.2](docs/release-0.6.2.md): require explicit opt-in for screen video capture.
- [0.6.1](docs/release-0.6.1.md): supported-toolchain reporting fixture fixes.
- [0.6.0](docs/release-0.6.0.md): explicit reuse of app-owned providers.
- [0.5.1](docs/release-0.5.1.md): keyboard shortcuts and reporting presentation fixes.
- [0.5.0](docs/release-0.5.0.md): protected developer settings and provider diagnostics.
- [0.3.1](docs/release-0.3.1.md): Firebase/native setup alignment.
- [0.3.0](https://github.com/matteozajac/MZAppFoundation/releases/tag/0.3.0): screen and voice bug reporting.
- [0.2.0](https://github.com/matteozajac/MZAppFoundation/tree/0.2.0): structured error logging.
- [0.1.0](https://github.com/matteozajac/MZAppFoundation/tree/0.1.0): initial reusable foundation.

Older tags predate the added license and public documentation files. A future
release must include those files in its own source archive.
